High-level technical details
- Chart placement and overlap detection:
  - Project A: Labels placed at the bar top center without collision checks (expected to overlap for dense or mixed-height bars).
  - Project B: For each label, figure/renderer is used to compute text bbox, and if overlaps occur with any previously placed label, the label is shifted upward by a margin (re-computed until no overlap or a max attempts threshold). This prevents label overlaps adaptively.
- Contrast considerations:
  - ChartGeneratorPost computes relative luminance and contrast ratios. If text color contrast vs. bar color is insufficient (< 4.5), it chooses an alternative (white/black).
- Tests:
  - The test suite uses the saved fig renderer to compute bounding boxes for accurate overlap detection.
  - Tests produce metrics: overlap (boolean), rect_count, min_vertical_gap_px, low_contrast (boolean).
- Accessibility:
  - Project B includes ARIA attributes in HTML and improved color contrast for accessibility.
