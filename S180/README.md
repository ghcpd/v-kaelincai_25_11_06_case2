# Feature Enhancement Experiment

See Project_A_PreFeature_UI and Project_B_PostFeature_UI folders. Run `./run_all.sh` to execute all tests and gather results. Use `bash` on Windows (Git Bash) or adapt to PowerShell.

Each project has its own run_tests.sh to install dependencies and run pytest. Results and logs are stored in respective `results/` and `logs/` directories.
